About

What this is, and who makes it

CSNL Module Picker is a free, independent timetable builder for UCD's Computer Science (Negotiated Learning) master's. UCD publishes the module list, the credits and the class times; it does not publish one view that turns a selection into a clash-free week. This site builds that view from UCD's own pages.

  • Maintainer Parth Soni
  • Status Independent, not UCD
  • Cost Free, no account
  • Source Public on GitHub

Why it exists

Choosing a CSNL year means reading a streams list of modules, checking how many credits each carries, and then discovering - usually too late - that two modules you wanted are timetabled at the same hour in the same trimester. The information is all public, but it lives in three different places and changes between semesters. This site joins those pages into one view so a selection can be tested before registration opens.

What it actually does

  • Lists every CSNL module grouped by stream and theme, with credits, core or optional status, semester and the module's own comments.
  • Fetches live class times for the modules you select from UCD's General Reference Timetable, including day, time, weeks, trimester and room.
  • Draws the week for Autumn, Spring or both, and marks any classes that overlap. Classes at the same time in different trimesters are not called a clash, because they never run together.
  • Plans toward a credit target. The planner searches for clash-free combinations at 30, 60 or 90 credits and can avoid 9am starts, avoid Fridays or cap how many classes land on one day.
  • Filters for exam-free modules using the assessment components listed on each module's UCD page, and has a no-final-exam plan mode.
  • Keeps several timetables that you can name, compare and export as JSON.

Where the data comes from

Everything is read from UCD at the moment it is needed. The module list and stream structure come from UCD's CSNL streams page; module descriptions and assessment components come from UCD's module catalogue; class times come from UCD's General Reference Timetable. The catalogue is re-checked on request and refreshed twice a month, so modules UCD adds appear on their own and modules UCD withdraws stop being offered.

Timings are for the current academic year only - UCD advances it around 1 August. If UCD has not published a timetable for a module yet, the site says so rather than showing last year's times, because a stale room is worse than an empty one.

What it is not

This is a planning aid, not a UCD service. It cannot register you, reserve a place, confirm prerequisites, or override a programme rule. Capacity limits, registration windows and assessment regulations belong to UCD, and UCD's systems and staff are the authority on them. Always confirm a final selection in UCD's own system before you register.

Why trust the numbers

The site shows its own provenance rather than asking you to take it on faith: a badge says whether the module list was re-verified against UCD's page on this visit, and a data line shows when timings were fetched. When UCD is unreachable, the site reports the failure instead of serving an old timetable as if it were current.

Found a wrong time or a missing module? That is worth reporting - see Contact. The source code and issue tracker are public at github.com/parth-soni-10/UCD-CSNL-Module_Picker.
