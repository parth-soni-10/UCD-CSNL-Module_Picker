# CSNL Module Picker

**Live site:** https://ucdcsnlmodulepicker.pages.dev

A module picker for UCD Computer Science students that builds a clash-free weekly timetable, then keeps itself current: everything that can change year to year is fetched from UCD on every page load.

## What it does

- **Clash-free timetables** - pick modules and see a weekly grid with no overlaps, across Autumn, Spring or both
- **Plan by credits** - the planner finds clash-free combinations for a 30, 60 or 90-credit target
- **Live class times** - day, time, weeks and room come from UCD's General Reference Timetable for the target academic year, so a new year needs no code change
- **Live module list** - streams, core/optional flags, semester, credits and comments come from UCD's own CSNL page; modules UCD adds appear by themselves
- **Add any UCD module code**, even one outside the list
- **Clear failure states** - a module with no published timetable says so, rather than showing last year's times
- **All / Autumn / Spring filter** on the grid and in clash detection
- **Suggestions** from a form that works with or without JavaScript

## Where the data comes from

Timings and offerings come from UCD's General Reference Timetable; the module list and its core/optional flags come from UCD's CSNL streams page. The catalogue is re-checked on every request and twice a month by a scheduled run, with a committed list as the last-resort fallback. The timetable proxy only fetches codes the live catalogue knows.

## For agents and crawlers

- `/llms.txt` is the compact guide: what the site is for, the JSON endpoints and their shapes, and the limits.
- `GET /` (and `/about`, `/contact`, `/privacy`) negotiates `text/markdown` and answers `Vary: Accept`; `/index.md`, `/about.md`, `/contact.md` and `/privacy.md` always return Markdown.
- An unknown path asked for Markdown gets a Markdown 404 that links the sitemap and `llms.txt`; browsers get the HTML [`404.html`](404.html).
- The homepage carries canonical, Open Graph/Twitter metadata and JSON-LD for the `Organization` (with `contactPoint` and `PostalAddress`), the `WebSite` and the `SoftwareApplication`.
- `og-image.png` is generated by `python3 tools/make-og-image.py` (generation-time only; the PNG is committed).

## Notes

- Not an official UCD service. Sources: [General Reference Timetable](https://www.ucd.ie/students/course_search/generalreferencetimetable/) for timings, [CSNL streams](https://www.ucd.ie/cs/study/postgraduate/nlstreams/) for the module list.
- Selections, added module codes, the theme choice and cached timings are kept in your browser's `localStorage`.

## Built with

Vanilla **HTML / CSS / JavaScript** with a **service worker**, served by one **Cloudflare Pages** project whose functions proxy UCD and hold the catalogue in KV. No runtime dependencies.
