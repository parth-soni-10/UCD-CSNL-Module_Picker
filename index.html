How to use this timetable planner

How clashes are detected

Choose a module and one of its published class offerings. The timetable compares day, start and end times, and teaching weeks; classes that overlap in time and run in a shared week are flagged. Autumn and Spring weeks are kept separate. The plan finder uses the same clash rules to suggest compatible choices.

What “exam-free” means

“Exam-free” means the assessment information currently available does not show a final-exam component. It is not a promise that a module has no exams: assessment details may be incomplete or change, so check the current UCD module page before planning around it.

Data sources and limits

The fallback list below is derived from the UCD CSNL streams page. Timetable data comes from UCD’s General Reference Timetable; assessment details are read from UCD module pages. This is an independent student tool, not an official UCD service; verify offerings, times and requirements with UCD.

Frequently asked questions

How does timetable planning work?

Choose modules and class offerings to build a weekly timetable. The planner compares class days, times and teaching weeks, and searches for combinations that avoid overlapping scheduled classes. Always confirm your final choices with UCD.

What does exam-free mean?

It means the currently available assessment information does not show a final examination component. It is not a guarantee that a module has no exam; check the current UCD module page before choosing.

Where does the module and timetable information come from?

The module list comes from UCD’s CSNL streams page, timetable details from UCD’s General Reference Timetable, and assessment information from UCD module pages. Data can be incomplete or change; verify it with the source.

Is this an official UCD service?

No. This is an independent, unofficial student planning tool. It is not affiliated with, endorsed by or operated by University College Dublin.
