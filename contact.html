This is a one-person project. Reports of a wrong timing, a module UCD offers but this site omits, or a page that breaks are genuinely useful — they are read by the maintainer and usually fixed in the next deploy.

Email

Write to soni.soni.parth@gmail.com for anything that should not be public: a data error, a module that is missing, a privacy or removal request, or a question about how the site works. There is no support contract and no guaranteed response time; messages are answered when they can be acted on.

The suggestion form

The homepage has a Suggestions panel at the bottom of the page. It is the right place for "please add this module", "this room looks wrong" or "this module has no timetable on UCD yet". A suggestion sent there is stored with the site so it can be worked through; an optional email address is kept only so a reply is possible.

Discord

UCD CS NL students run a Discord with a channel per CSNL module: discord.gg/6Jp2hVFYdt. For questions about a module's workload, assessment style or what a lecturer is like, other students there usually answer faster than this site's maintainer can.

Source code and issue tracker

The site is open source at github.com/parth-soni-10/UCD-CSNL-Module_Picker. Timetable-parsing failures and feature requests can be filed there as issues, which keeps the discussion next to the code that would change.

What this site cannot help with

It cannot change your registration, add you to a full module, answer a fees or visa question, or override a programme rule. Those belong to your programme office and the UCD Student Desk. If a module looks unavailable here, UCD's own system is the one that decides.

Before reporting a timing: open the module on UCD's General Reference Timetable and compare. If UCD has changed it, a reload of this site should pick the change up; if it has not, the report is exactly what is needed.
